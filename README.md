## Hi, I'm Maca 👋

Fullstack developer and fullstack musician, based in Buenos Aires, Argentina.

I build software end to end, from the database to the deploy, and I love turning repetitive work into systems that run on their own.

## What I do

**Frontend.** Fast, accessible interfaces with React, Next.js and Astro, styled with Tailwind. Installable PWAs that feel at home on a phone, and real-time screens for live TV that can't freeze on air.

**Backend and APIs.** Node.js and TypeScript services, REST APIs, authentication (Google login, email, invitations), payments and transactional email. SQL and NoSQL databases: MySQL, PostgreSQL, MongoDB, Cloudflare D1.

**AI agents and orchestration.** I design and run multi-agent systems: specialist agents with clear roles, a coordinator that routes and reviews their work, shared memory, scheduled routines and human-in-the-loop approvals. I build the harness around the model (tools, permissions, context, evals and guardrails) so agents can do real work safely and reliably.

**Edge and infrastructure.** I deploy on Cloudflare Workers with D1, R2 and KV, keep an eye on CPU and performance, and automate deploys and migrations so shipping is boring.

**Mobile.** Cross-platform iOS and Android apps with React Native, native Android with Kotlin, and web apps built mobile-first.

**Broadcast and streaming.** Live graphics, control panels and rundown tools for TV and streaming, wired into OBS.

**Music.** Composing, recording and mixing. Being a musician shapes how I think about timing, live shows and the people on the other side of the screen.
